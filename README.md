# HR Analytics Dashboard – Power BI

## Project Overview

The **HR Analytics Dashboard** is a data analysis and visualization project created using **Microsoft Power BI**.

The purpose of this project is to analyse employee-related data and understand important HR metrics such as job satisfaction, monthly income, performance, work-life balance, education level, marital status, job level, and employee count.

The dashboard provides an interactive way to explore employee data and identify patterns that can support better HR and workforce decisions.



## Dataset

The dataset contains employee information related to different HR and workforce attributes.

The main fields used in the analysis include:

- Gender
- Department
- Education Level
- Marital Status
- Employee Count
- Job Satisfaction
- Monthly Income
- Performance Rating
- Environment Satisfaction
- Work-Life Balance
- Years at Company
- Job Level

The dataset was organized and cleaned before importing it into Power BI for analysis.



## Data Cleaning and Preparation

Before creating the dashboard, the dataset was reviewed and prepared for analysis.

The main steps included:

- Organizing the data into proper rows and columns.
- Checking missing and incomplete values.
- Checking duplicate records.
- Standardizing categorical values.
- Checking numerical fields.
- Applying appropriate data types.
- Preparing the cleaned dataset for Power BI.

This helped ensure that the data was suitable for analysis and visualization.



## Dashboard

The final dashboard was created using **Microsoft Power BI**.

It includes interactive filters, KPI cards, and different charts to analyse employee and HR-related information.

## Interactive Filters

The dashboard includes filters for:

- Gender
- Department
- Education Level

These filters allow users to analyse specific groups of employees and understand how HR metrics change based on different selections.



## Key Insights

Some important observations from the dashboard include:

- Employee satisfaction levels vary across different job satisfaction ratings.
- Research & Development and Sales show higher employee counts compared with Human Resources.
- Monthly income generally increases with higher job satisfaction levels.
- Employee distribution varies across different education levels.
- Married and single employees represent significant portions of the workforce.
- Higher job levels are associated with higher monthly income.
- Work-life balance varies across departments.
- The dashboard helps compare employee satisfaction, income, performance, and workforce characteristics in one place.
